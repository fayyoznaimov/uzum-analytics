# Uzum Монитор — агент для домашнего ПК (без браузера)

Снимает карточки конкурентов и позиции в поиске **без открытого браузера**: достаточно включённого компьютера в домашней сети. С серверных IP каталог Uzum закрыт капчей, поэтому агент запускается именно дома.

## Установка (Windows, один раз)

1. Установите Node.js 20+ (https://nodejs.org, кнопка LTS).
2. Скопируйте папку `uzum-monitor-agent` на ПК (например, в `C:\uzum-monitor`).
3. В кабинете аналитики откройте «Конкуренты» → «Код для расширения», затем в командной строке:
   ```
   cd C:\uzum-monitor
   node collect.mjs --pair 123456
   ```
4. Проверка: `node collect.mjs` — должно напечатать «Готово: карточек N…».

## Автозапуск каждые 3 часа (Планировщик задач)

Планировщик задач → «Создать простую задачу» → имя «Uzum Монитор» → «Ежедневно» → далее в свойствах задачи на вкладке «Триггеры» поставьте «Повторять каждые 3 часа». Действие: программа `node`, аргументы `collect.mjs`, рабочая папка `C:\uzum-monitor`.

Если сервер доступен по другому адресу, задайте переменную `UZUM_MONITOR_BASE`, например `http://172.0.30.4:3200/api`.

Агент читает только публичные страницы uzum.uz и отправляет данные только на ваш сервер. Токен подключения лежит рядом в `uzum-monitor-token.txt` — не выкладывайте его.
