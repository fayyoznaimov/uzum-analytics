# Uzum Analytics — конкуренты и слоты поставок (Chrome-расширение)

Расширение делает две вещи из браузера владельца:

1. **Тайм-слоты FBO-поставок** (каждые 2 минуты). Сервер даёт список накладных, для которых включена автобронь
   (экран «Поставки»). Расширение спрашивает свободные слоты в кабинете Uzum, бронирует самый ранний слот не
   ближе 2 дней. Если слот уже есть, а освободился день раньше, переносит туда все накладные группы одной поездкой.
   Последнюю из трёх смен слота бот не тратит — она остаётся владельцу. Слот, до которого меньше 48 часов, не
   трогает: такой перенос Uzum штрафует. Результат уходит на сервер, сообщения приходят в Telegram.
   С сервера кабинет часто закрыт Cloudflare, из браузера владельца — нет. Пока расширение отчитывается,
   серверный бот кабинет не трогает.
2. **Монитор конкурентов** (раз в N минут, по умолчанию 180). Снимает публичные данные карточек конкурентов на
   uzum.uz и позиции собственных товаров в поиске.

Для слотов расширение берёт вход владельца в кабинет из открытой вкладки seller.uzum.uz. Этот вход хранится
**только в этом Chrome** и на сервер аналитики не отправляется. Данные уходят только на сервер владельца (адрес
настраивается в окне расширения). Никаких внешних библиотек и сторонних доменов.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (переключатель справа вверху).
3. Нажмите «Загрузить распакованное» и выберите папку `extensions/uzum-monitor`.
   Если расширение уже стояло — нажмите у него кнопку «Обновить» (круглая стрелка), чтобы подтянуть новую версию.

## Подключение

1. В Uzum Analytics откройте **«Склад и поставки» → «Поставки»** и нажмите **«Код для расширения»** —
   появится одноразовый 6-значный код (действует 10 минут). Та же кнопка есть на экране «Конкуренты»
   (`/competitors`, в меню его нет).
2. Нажмите на иконку расширения, при необходимости поправьте «Адрес сервера»
   (по умолчанию `http://172.0.30.4:3200/api`), введите код и нажмите **«Подключить»**.
3. Статус должен смениться на «подключено». Токен сохраняется в расширении,
   повторно вводить код не нужно.
4. Откройте или обновите вкладку кабинета **seller.uzum.uz** — в окне расширения строка «Вход в кабинет»
   станет «есть». Дальше вкладку можно закрыть: вход запоминается, а при открытом кабинете обновляется сам.

## Как проверить работу

- Слоты: в окне расширения нажмите **«Проверить слоты сейчас»** — появится строка «Проверено …» с числом
  групп накладных и свободных слотов. На экране «Поставки» у накладной обновится «проверено …».
- Конкуренты: нажмите **«Собрать сейчас»** — сбор занимает несколько минут (между карточками пауза 1,5–3 с,
  не больше 50 карточек за прогон). После прогона появится строка «Последний прогон: …».

## Если что-то не работает

- «Вход в кабинет: нет» или ошибка 401 — откройте seller.uzum.uz в этом Chrome и войдите.
- Сервер недоступен (компьютер в другой сети) — расширение работает по последнему заданию (до суток)
  и отправит отчёт, когда сервер снова будет доступен.
- Лог ошибок смотрите в консоли фонового скрипта: `chrome://extensions` → карточка расширения → ссылка
  **service worker** → вкладка Console.
