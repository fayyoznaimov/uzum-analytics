# Uzum Analytics — монитор конкурентов (Chrome-расширение)

Расширение раз в N минут (интервал задаёт сервер, по умолчанию 180) снимает публичные данные
карточек конкурентов на uzum.uz и позиции собственных товаров в поиске, и отправляет их на
локальный сервер Uzum Analytics. Работает только пока открыт браузер владельца — с серверных IP
каталог Uzum закрыт антиботом, из браузера пользователя страницы доступны.

Расширение читает **только публичные страницы uzum.uz** (карточки товаров и выдачу поиска)
и отправляет данные **только на сервер владельца** (адрес настраивается в окне расширения).
Никаких внешних библиотек и сторонних доменов.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (переключатель справа вверху).
3. Нажмите «Загрузить распакованное» и выберите папку `extensions/uzum-monitor`.

## Подключение

1. В кабинете Uzum Analytics откройте экран **«Конкуренты»** — там показывается
   одноразовый 6-значный код подключения.
2. Нажмите на иконку расширения, при необходимости поправьте «Адрес сервера»
   (по умолчанию `http://172.0.30.4:3200/api`), введите код и нажмите **«Подключить»**.
3. Статус должен смениться на «подключено». Токен сохраняется в расширении,
   повторно вводить код не нужно.

## Как проверить работу

1. В окне расширения нажмите **«Собрать сейчас»** — сбор занимает несколько минут
   (между карточками выдерживается пауза 1,5–3 с, не больше 50 карточек за прогон).
2. После прогона в окне расширения появится строка «Последний прогон: …» с временем,
   числом снапшотов, позиций и ошибок.
3. На сервере свежие данные видны на экране «Конкуренты».

## Если что-то не работает

Лог ошибок (в том числе ошибок разбора ответов каталога Uzum) смотрите в консоли
фонового скрипта: `chrome://extensions` → карточка расширения → ссылка
**service worker** → вкладка Console.
