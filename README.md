# Uzum Analytics v1.0

Отдельный кабинет аналитики продавца Uzum: продажи, прибыль, себестоимость, склад, поставки, цели, Telegram и кошелёк с прогнозом попадания денег в корзину вывода.

## Запуск

```bash
unzip uzum-analytics-v1.0-full.zip
cd uzum-analytics-v1.0
chmod +x setup.sh scripts/*.sh
./setup.sh
```

После запуска:

1. Откройте сайт.
2. Войдите под администратором.
3. В настройках добавьте новый Uzum token, Shop ID, Telegram Bot Token и Chat ID.
4. Нажмите «Проверить».
5. Запустите синхронизацию.
6. Заполните себестоимость и логистику до склада.
7. Проверьте Кошелёк: дата корзины должна считаться от `dateIssued`.

## Главные разделы

- Главная — продажи, выплата, прибыль, расходы, цели, склад, будущие деньги.
- Кошелёк — по дням, когда деньги попадают в корзину вывода, и отдельно график выплат.
- Товары — финансовая расшифровка по карточкам.
- Часовые продажи — динамика по часу/дню/неделе.
- Склад — отчёт Uzum, сколько должно быть, потенциальная выплата и прибыль.
- Поставки — статусы, история, уведомления, FBS-слоты.
- Себестоимость — cost, упаковка, логистика до склада, налог и последняя фактическая ставка рекламы каждого товара из Uzum.
- Реклама — фактические расходы finance/expenses, ROAS/ДРР и явно помеченные предварительные оценки только там, где факт ещё не опубликован.
- Отзывы — AI-логика и inbox-каркас без фейковых отзывов.
- Качество карточек — скоринг и приоритеты улучшений.
- Цели — недельные и месячные цели.

## Проверка на сервере

```bash
npm ci
npm run prisma:generate -w apps/api
npm run test -w apps/api
npm run test:types:api
npm run lint -w apps/web
npm run build -w apps/web
./scripts/smoke-test.sh
SMOKE_TEST_UZUM=1 SMOKE_TEST_TELEGRAM=1 ./scripts/smoke-test.sh
```

Локальный архив не содержит `.env`, токенов, `node_modules`, `.next` и секретов.
