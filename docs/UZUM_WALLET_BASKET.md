# Кошелёк и корзина вывода Uzum

## Главный принцип

Система различает две даты:

1. **Дата корзины вывода** — когда деньги становятся доступными в кабинете для вывода.
2. **Дата выплаты по графику** — когда Uzum отправит деньги по выбранному расписанию.

Дата корзины считается от `dateIssued`, то есть от фактической выдачи товара покупателю:

```text
dateIssued + 10 полных календарных дней удержания + следующий день
```

Пример:

```text
Товар выдан: 1 июля
10 полных дней удержания: 2–11 июля
В корзину вывода: 12 июля
```

## Почему не от даты заказа

Дата заказа показывает, когда покупатель оформил заказ. Для денег это не подходит: товар могут получить позже, отменить или вернуть.

## Возвраты

Если товар уже был выдан, но потом появился возврат, система создаёт отрицательное финансовое событие и уменьшает:

- сумму в корзине;
- сумму по графику выплат;
- прогноз чистой прибыли;
- cashflow.

## API поля v1.0

```text
payoutForecast.basketDailyRows   — по дням, когда сумма попадает в корзину
payoutForecast.payoutDailyRows   — по дням выплаты по графику
payoutForecast.summary           — общие суммы: корзина, удержание, график, возвраты
```

## Что нужно сверять

Фактическое поступление на расчётный счёт подтверждается только историей выплат Uzum или банковской выпиской. Статус в системе до такой сверки является прогнозом.
