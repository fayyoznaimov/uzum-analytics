# Audit report v1.0

## Что изменено после замечания по UI

Проблема v1.0: UI-прототип был сфокусирован почти только на кошельке, а часть реальных страниц в Next.js оставалась placeholder-страницами.

Исправление v1.0:

- Полный UI-прототип показывает все ключевые блоки продукта.
- В Next.js заменены placeholder-страницы на реальные компоненты:
  - `AdsClient`
  - `MonthlyClient`
  - `ReviewsClient`
  - `QualityClient`
- Остальные существующие разделы сохранены:
  - Dashboard
  - Wallet
  - Products
  - Hourly
  - Warehouse
  - Supplies
  - Costs
  - Goals
  - Settings

## Финансовая логика

Сохранена модель v1.0:

- `dateIssued`
- 10 полных дней удержания
- дата попадания в корзину вывода по дням
- отдельная дата выплаты по графику
- возвраты уменьшают прогноз корзины и будущих выплат

## Ограничения

В текущей среде npm-зависимости не установлены, поэтому сборку и тесты нужно выполнить на VPS после `npm ci`.
