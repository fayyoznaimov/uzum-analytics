# Uzum Analytics v1.0 — Full UI restored

## Главное

- Вернул все основные разделы в интерфейс: Главная, Кошелёк, Товары, Часовые продажи, Ежемесячные отчёты, Реклама, Склад, Поставки, Себестоимость, Отзывы, Качество карточек, Цели, Настройки.
- Кошелёк оставлен в правильной финансовой логике: `dateIssued` → 10 полных дней удержания → корзина вывода → график выплат Uzum.
- Добавлен дневной календарь сумм, которые попадут именно в корзину вывода.
- Возвраты уменьшают прогноз корзины, будущих выплат и прибыли.
- Улучшен UI: новый полный preview, таблицы, карточки, блоки приоритетов, календарь, нормальные пустые состояния.

## UI

- Убраны простые placeholder-страницы для рекламы, месячных отчётов, отзывов и качества карточек.
- Добавлены полноценные клиентские компоненты:
  - `AdsClient`
  - `MonthlyClient`
  - `ReviewsClient`
  - `QualityClient`
- Обновлены стили `globals.css` для full-dashboard вида.

## Что важно

Фактические данные рекламы, отзывов и глубокого качества карточек появятся после подключения соответствующих отчётов/API. До этого страницы показывают расчётную модель и точки контроля, но не выдумывают реальные рекламные кампании или отзывы.


## v1.0.1

- Docker base image changed from Node 22 Alpine to Node 20 Alpine to avoid npm 10.9.x `Exit handler never called` during `npm ci` on Docker Desktop/Windows.
- `npm ci` now runs with `--no-audit --no-fund --loglevel=warn` for more stable container builds.
- Added `RUN_ON_WINDOWS.md`.
